This link points at a file stored with Gstore. To download it you need Gstore itself — but you do not need an account of any kind, and you do not need the sender's Google accounts.

  1. Install Gstore if you do not have it — macOS, Windows or Linux. It is a free download.
  2. Open the Files tab and click Open link…
  3. Paste this link. Gstore shows you what the file is and how big it is before downloading anything, then asks where to save it.

This page never sees the link. Everything that identifies the file sits after the #, and browsers never send that part of a URL to a website. It is read only by the copy button above, in your own browser. Nothing about what you are downloading reaches us — we run no server that could receive it.

Files shared this way move directly between Google and whoever holds the link. The sender can withdraw it at any time, after which it stops working. Privacy policy · About Gstore
