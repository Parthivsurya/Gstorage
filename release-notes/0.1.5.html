Gstore 0.1.5

26 November 2026 · previous release 0.1.3, 28 October

Folders, in both directions. And everything Gstore writes now lives in one tidy folder on each account instead of loose in your Drive.

Upload a folder

Upload folder sits beside Upload file on the Files tab. The folder's structure is kept, and its files are spread across whichever linked accounts have room.

A folder larger than any single account needs nothing special. Each file is placed on its own, so a 40 GB folder simply fills two 15 GB accounts between them; and a single file too big for every account is still split into 50 MB pieces across several, exactly as it always was.

Before anything starts you are told how many files and how much data, so a folder is never a surprise. Dependency directories are left out — node_modules, __pycache__, build, dist and the like. They are rebuilt from a manifest rather than written by hand, and they dwarf everything else: one project folder tested here went from 17,995 files to 60. The count left out is shown, never hidden, and hidden files and symlinks are skipped too.

Download a folder

Select a folder and press Download. It is rebuilt on disk from wherever its pieces live — across accounts, and across the 50 MB chunks of any file that was split — with every file checked against its checksum on the way in.

Both directions are faster, and both can be resumed

  • Eight files at a time, up and down, rather than one after another.
  • Small files go up in a single request instead of opening a resumable session they have nothing to resume, which is most of what made a folder of small files slow.
  • Stopping is not starting over. Both directions skip what is already there, so a transfer interrupted at file 200 of 282 does the remaining 82 next time, not all 282.

Your Drive stays tidy

Until now every file Gstore uploaded landed loose in My Drive's root — and since a large file is stored as 50 MB pieces, a single 20 GB upload scattered more than four hundred of them across the top level of your own Drive.

Everything now goes inside a single Gstore folder on each account. Tidy up my Drive, on the Storage tab, moves files uploaded by earlier versions into it.

Tidying moves nothing but a label. Drive is asked to change each file's parent, so nothing is re-uploaded, nothing is re-downloaded, and no file identifier changes — which means share links you have already sent keep working. 414 files took about 70 seconds here. You can also rename or move the Gstore folder afterwards; Gstore follows it.

Large files start sooner

A file split across accounts used to be read from end to end to compute its checksum before the first piece was sent — minutes, on a 20 GB file, with a progress bar that could not move. The checksum now runs alongside the upload, so the transfer begins at once. The same check is still made, and a download still verifies against it.

Upgrading

Replace the application. The local index updates itself on first launch and keeps everything: linked accounts, stored files, and existing shares. Files uploaded by earlier versions stay exactly where they are in your Drive until you choose to tidy them.
