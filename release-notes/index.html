Gstore release notes

Notes for each published version.

  • 0.1.3 · 28 October 2026

    Fixes opening a shared link for files over about 100 MB, which failed every time in 0.1.2.

  • 0.1.2 · 28 October 2026

    Share a stored file by link — the recipient needs no account of any kind. Also fixes the in-app update check, which had never worked in a shipped build.

  • 0.1.0 · 24 October 2026

    Parallel chunked transfers in both directions, resumable uploads and downloads, Linux builds, and in-app update notices.

  • 0.0.4 · 19 October 2026

    Packaging only: download links that stay put across releases, correct version metadata in the bundles, and the real app icon.

Versions before 0.0.4 have no written notes; see the GitHub releases.
