Gstore 0.1.8

28 November 2026 · previous release 0.1.7, the same day

You can watch an update arrive, and find out what Gstore is without leaving it.

A progress window for updates

Downloading a new version reported a bare percentage in the banner. A release is 70–100 MB over whatever connection you happen to have, and a percentage cannot answer the only question being asked of it: is this working, or is it stuck?

There is now a window showing how much has arrived of how much, the current speed, and the time remaining. The speed is measured over the last few seconds rather than the whole download, so it describes what your connection is doing now instead of being flattered by a fast first second.

Two smaller things while we were in there. Cancelling is no longer reported as a failure — being warned for doing what you asked for is its own small insult. And checking the signature on a 76 MB file now says so, rather than leaving a window that appears to have stopped at 100%.

A "?" in the corner

Bottom right of the window. It opens an About panel: the version, who wrote Gstore, what it does in a sentence, and links to the privacy policy, the licence, the release notes, the source and the issue tracker.

It also says the thing most worth knowing. Gstore keeps the only record of which account each file lives on. Back up the index from the Storage tab, and keep that backup somewhere other than the machine running Gstore. Without it, a large file's pieces are scattered across accounts with nothing left to reassemble them.

All of this existed already — on a website. The person deciding whether to hand Gstore their Google account is looking at the app.

Upgrading

If you are on 0.1.7, this is the first update Gstore can install for you: press Download and it fetches the build, verifies its signature, replaces itself and restarts. Earlier versions still need the app replaced by hand.
